# 使用 GUI

带你逛一圈这个应用 — 包括那些容易被错过的小功能。
每个设置都有提示: 把鼠标悬停在旁边的 ⓘ 图标上即可查看。

Linux 会先显示启动窗口，展示安装检查的进度，再打开界面。
安装或更新后的首次启动需要更长时间，启动错误会留在屏幕上。
不支持 NTFS 或网络磁盘，请使用 ext4、Btrfs 或 XFS 磁盘。

## 队列

- 使用**添加文件**按钮（旁边的文件夹图标可添加整个文件夹）添加视频或图像，
  或者直接把它们**拖放**到队列上。
- 超过 20 个项目时，使用队列下方的箭头切换页面。所有页面都会按顺序处理；
  拖动只能调整当前页面内的顺序。
- **拖动队列项的把手即可调整任务顺序** — 处理按从上到下的顺序进行。
- 每个视频都有**剪刀**按钮打开[区间编辑器](segments.md)，还有**播放**按钮可在
  修复视频播放器中打开且保持暂停。使用**三点**菜单（或右键点击该行）可打开输入
  文件夹。已完成视频会在支持的文件管理器中显示输出文件。图像行也有文件夹菜单；
  还可复制相关路径、打开已完成的输出，或把已完成、失败或跳过的项目重新放到队列
  末尾。叉号可移除任何队列项。
- 处理过程中，每个队列项都会实时显示进度、FPS 和剩余时间。
- 每次点击**开始**时，Jasna 都会从上到下处理队列中保留的所有任务，
  包括已完成或失败的任务。更改设置后无需重新添加文件，直接再次开始即可。
- **停止**会结束这次处理。被中断的任务回到**等待中**，下次开始时会从头
  处理整个队列。写了一半的输出文件会留在磁盘上，并按照下方的
  **文件冲突**设置处理。
- **清除已完成**移除已完成的任务；**清空**清空整个队列。

## 输出设置

- **与输入相同**会把每个结果写到原文件旁边。选择文件夹后，点击输出位置旁的按钮
  即可返回此模式。
- 可以直接输入文件夹路径，也可以使用文件夹按钮。两种方式都会关闭**与输入相同**。
- **输出文件名模板**控制输出文件名 — `{original}` 代表输入文件名。
  如果某个模板会覆盖已有文件，受影响的队列项会立即高亮显示。
- **文件冲突**决定输出文件已存在时的处理方式: **自动重命名**
  （默认，安全）、**覆盖**或**跳过**。

## 预设

设置面板顶部的工具条可保存完整的设置组合。为你处理的每类内容创建
一个预设（例如“1080p 快速”和“4K 最佳质量”），一键切换。Jasna 会在
重启后记住你上次使用的预设。

## 每个视频的单独设置

在[区间编辑器](segments.md)中选择的检测模型和置信度会**按队列中的
每个视频单独记住**，因此同一队列中的不同视频可以使用不同的检测设置。

## 修复视频播放器

选择页眉中的**视频播放器**，即可边修复边观看视频。选择检测模型、
置信度以及可选的 RTX Super Resolution 或 unet-4x，点击**选择视频**，
然后按普通播放按钮。按空格键可播放或暂停，左右方向键可前后跳转 30 秒。
播放期间可以使用跳转、音量和全屏控制。全屏模式会在保持源视频宽高比的
前提下尽可能放大视频。将鼠标移到屏幕底部边缘会显示播放面板，移出面板后
会再次隐藏。

在页眉播放器中，**选择视频**会打开文件选择器。播放期间点击它会先停止当前
修复。更改检测模型、置信度或二次修复时，也会从当前播放位置重新加载修复管线。
播放状态会显示播放位置之后已经准备好的修复视频秒数。如果缓冲反复降到零，说明
当前设置下的修复速度无法维持实时播放。

播放器不会生成输出文件。如果修复速度比视频播放慢，音频会暂停，等待更多
修复画面准备好。只有在队列处理和修复预览都空闲时才能使用。

## 交互式图像修复

对于静态图像，**交互式处理图片**（位于 SD 1.5 设置部分）会打开一个
左右对比视图: 逐张浏览图片、尝试不同种子、对比原图、蒙版和修复结果，
只保存你喜欢的变体。比反复重跑整个任务来试验要快得多。

## 系统检查

每个版本首次启动时，Jasna 会运行系统检查（GPU、驱动、内存、安装
路径）。你随时可以从头部重新运行它 — 在更新驱动后或出现异常时很有用。

## 其他值得了解的功能

- **语言**: 首次启动时跟随系统语言。之后可随时在头部的下拉菜单中切换界面语言（重启后完全生效）。
- **日志**: 底部工具条的日志按钮显示实时日志（最新 5000 条），带级别过滤和导出按钮 —
  反馈问题时请附上导出的日志。
- **系统状态**: 处理时底部工具条会显示 GPU、VRAM、内存和 CPU 占用。
- **激活**：在头部打开**激活 Jasna**，在线激活或手动输入激活密钥。状态标签显示此机器上的激活是否有效。

## 激活付费模型

在头部打开**激活 Jasna**，默认选择**在线**。**在线**和**手动**都会显示**机器密钥**，可以复制，不能编辑。

- **在线**：输入官方卖家提供的**许可证码**，点击**在线激活**。
- **手动**：复制机器密钥，在任意联网设备上打开[激活页面](https://jasna-activation.kruk2.workers.dev)，输入机器密钥和许可证码，或向官方卖家申请。**打开激活页面**会在浏览器中打开该页面。将返回的**激活密钥**粘贴到 Jasna 并点击**激活**。

点击**在线激活**时，仅通过 HTTPS 向该服务发送许可证码和机器密钥。Jasna 确认返回的激活密钥适用于本机后，只保存此密钥，不保存许可证码。之后启动和修复时离线验证激活，不会定期联网检查。

两种方式共用每个许可证码的 **3 台机器或工作区**名额。为相同机器密钥重新获取激活密钥不会占用新名额。只有所有者可以释放名额或批准更换，买家不能自行删除注册。释放名额不会禁用已为旧版离线应用签发的密钥。密钥只包含已购买的模型版本。

**RunPod 或 Vast** 云激活仅限在受支持的容器内通过 Linux 官方版 [CLI](cli.md#激活) 使用。

在线激活失败时，请选择**手动**，从另一台联网设备使用激活页面，或将许可证码和机器密钥发送给官方卖家申请。服务无法保证在中国大陆等地区可用；同样适用 3 个名额的限制。

密钥被拒绝时，请检查机器密钥并重新复制完整密钥。旧版激活格式的密钥须向官方卖家申请替换。许可证码仅在 Buy Me a Coffee 和 Unifans (kruk2) 出售。
